Чек-лист аудита кассы казино: 30 пунктов

Как пользоваться

Отвечайте по каждому ключевому гео отдельно: касса, которая хорошо работает в Германии, может терять депозиты в Канаде. Где не хватает данных, отметьте пункт как «не знаю» — это тоже результат: значит, вы не видите эту часть воронки.

1. Путь игрока до кассы

  1. Игрок может внести первый депозит сразу после регистрации, без лишних шагов.
  2. Форма регистрации не запрашивает данные, которые не нужны до депозита.
  3. Требования верификации понятны игроку заранее, а не всплывают в момент оплаты.
  4. Кнопка депозита видна на каждом экране, включая мобильную версию.
  5. Вы знаете, какая доля зарегистрированных игроков открывает кассу и какая доля делает первый депозит.

2. Касса

  1. Для каждого ключевого гео есть популярные локальные методы, а не только карты.
  2. Порядок методов зависит от гео игрока, а не одинаков для всех.
  3. Суммы по умолчанию соответствуют реальным депозитам в этом гео.
  4. Повторный депозит проходит в один-два клика с сохранённым методом.
  5. Сообщения об ошибках объясняют, что делать дальше, а не просто «ошибка оплаты».

3. Гейтвей и 3DS

  1. В 3DS 2 передаётся максимум данных об игроке и устройстве.
  2. Вы видите долю платежей, где игрок не завершил 3DS, по каждому провайдеру.
  3. Таймауты настроены так, что игрок не ждёт бесконечно и не платит дважды.
  4. Статусы транзакций и колбэки обрабатываются корректно: нет «зависших» депозитов.
  5. Карты сохраняются через токенизацию, и повторные платежи используют токен.

4. Роутинг и каскад

  1. По каждому ключевому гео есть минимум два провайдера для карт.
  2. Роутинг учитывает гео, BIN и банк-эмитент, а не просто распределяет трафик в процентах.
  3. Каскад настроен по кодам отказа: жёсткие отказы не повторяются.
  4. Учитываются правила повторов Visa и Mastercard, включая Merchant Advice Code.
  5. Вы знаете, сколько депозитов в месяц спасает каскад.
Услуга по темеРоутинг и каскадинг

Настраиваем смарт-роутинг и каскадинг депозитов: правила по гео, BIN и банку, каскад по кодам отказа и после 3DS, sticky routing. ТЗ для in-house гейта и настройка.

Подробнее об услуге

5. Провайдеры

  1. Вы знаете проходимость каждого провайдера по каждому гео и методу.
  2. Условия провайдеров (комиссии, резервы, сроки выплат) пересматривались за последний год.
  3. Есть резервный провайдер на случай сбоя или отключения основного.
  4. Вы сравниваете стоимость успешного депозита, а не только ставку комиссии.
  5. У каждого провайдера есть контакт для срочной эскалации.

6. Аналитика и процессы

  1. Проходимость разбита по провайдерам, методам, гео, BIN и банкам.
  2. Вы отдельно считаете проходимость попыток и конверсию игроков в депозит.
  3. Алерты о падении проходимости приходят раньше жалоб игроков.
  4. Отказы разбираются по типам: технические, банк-эмитент, антифрод, касса.
  5. У проходимости есть ответственный, который смотрит её каждый день.

Как оценить результат

  • 25–30 «да» — касса в хорошей форме, ищите точечные улучшения в слабых сегментах.
  • 15–24 «да» — есть заметные потери, начните с разделов, где больше всего «нет».
  • Меньше 15 — депозиты теряются на нескольких шагах сразу, имеет смысл полный аудит.

Если ответ «не знаю» встречается часто, начните с аналитики: без неё невозможно понять, какие изменения работают. Мы можем пройти этот чек-лист вместе с вами на интро-звонке и сказать, с чего начать.

Коротко

Сколько времени занимает самостоятельная проверка?

Если данные по проходимости доступны, пройти чек-лист по одному гео можно за пару часов. Сложнее всего обычно с пунктами по аналитике.

Чем чек-лист отличается от полного аудита?

Чек-лист показывает, где искать проблемы. На аудите мы сами разбираем данные и настройки, оцениваем потери и даём план изменений с приоритетами.
