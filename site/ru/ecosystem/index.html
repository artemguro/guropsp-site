Репутация

GURO ID

В iGaming резюме говорит о том, что человек заявляет. GURO ID показывает то, что подтверждено. Вы указываете контрагента, он подтверждает в Telegram — и только тогда запись появляется в обоих профилях.

✓

Подтверждает вторая сторона

Без ответа партнёра запись остаётся черновиком — накрутить рейтинг в одиночку нельзя.

✓

Приватно по умолчанию

Имена контрагентов и суммы скрыты. Публичен сам факт: партнёрство подтвердили обе стороны.

✓

Рейтинг остаётся вашим

Он принадлежит человеку, а не компании, и сохраняется при смене работы.

✓

Доска вакансий

Официальные вакансии верифицированных компаний, поиск по вертикали и должности.
